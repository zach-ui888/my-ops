## 安全版实现与边界

【源码已确认】最终运行目录为镜像 `/app`，代码为项目 `app/` 中的三个改版模块及 security、firewall、entrypoint。`reference/` 不提交、不进入构建、不作卷挂载。未复制 install.sh、docker/ml、.git。Compose 为合法 YAML 的 JSON 子集，便于用标准库进行离线结构检查。

- 只发布宿主回环 8787/7928，容器内监听 0.0.0.0 供端口映射；独立 bridge，无 host/pid host/privileged/socket。
- root **仅在容器内**运行，cap_drop ALL 后显式 NET_ADMIN/NET_RAW；read_only、no-new-privileges、TUN rw、/tmp tmpfs、专属 /data 卷、只读凭据挂载；不需要 SETUID/SETGID/SYS_ADMIN/MKNOD。
- 安全入口加载并验证管理员 secret；缺失/占位值/格式错误即退出。明文密码只在只读 secret 和进程内；/data/ui_auth.json 仅保存偏好。会话 secrets.token_hex(32) 在内存生成，不输出，重启失效。公共 VPNGate vpn/vpn 会写入 /data/vpngate_auth.txt（0600），不是管理员密码。
- 原始上游 print 与请求日志关闭，JSON 原始日志关闭；删除 Tee 使用、启动横幅、网页修改凭据 API、非加密出口探测。入口只输出固定生命周期事件。损失详细日志可观测性是有意取舍；网页状态仍显示诊断结果，不导出到外部。
- 配置只允许公共 IPv4、唯一 remote、受限内嵌 ca/cert/key；忽略允许列表中的上游可调选项并用固定策略重建，拒绝其他指令。不保留 persist-tun。开启服务器证书用途验证，禁压缩与脚本。CA 来自经 HTTPS 获取的节点配置，不等于独立验证节点运营者身份。
- DNS 套接字及业务 TCP 在连接前打 SO_MARK=0x56504e 并绑定 tun0；nft inet output 和 postrouting 规则丢弃该标记且输出接口不是 tun0 的包。启动先以事务安装规则，失败不启动代理。IPv6 业务目标被拒绝；不会产生未保护 IPv6 业务连接。代理只查询 A 记录，数字 IPv6 也会被拒绝。
- **kill switch 范围仅为带标记的代理 TCP/DNS**，不是整容器默认拒绝：VPNGate HTTPS API、节点握手/测速、系统控制面 DNS 必须走普通容器网卡才能引导建连。宿主其他应用不受保护。程序被攻陷后 NET_ADMIN 可修改规则，不能把规则视作防容器攻击者的隔离边界。
- 删除第三方归属富化，IP 类型过滤固定为“所有 IP”。严格配置、禁压缩与仅 IPv4 可能降低公共节点兼容率，不自动降低安全性换取连接成功。

【未验证】真实构建/启动、nft 内核支持和语法执行、NET_RAW 最小化可能性、VPNGate 当前配置兼容、Web 完整交互、既有 TCP 连接在 tun 删除后的实际行为、DNS 抓包、出口 IP、资源峰值、故障恢复。离线测试不证明上述事项。

【风险】基础镜像/包版本未锁摘要；无完整许可证正文；部署未验收；标准库 Web 不宜公网；公共节点不可信；只读 secret 对 Docker 管理员和容器 root 仍可见。管理员完成 README 验收前不可宣称生产就绪。

### 尚存风险

容器 root 持有 NET_ADMIN/NET_RAW，应用被攻陷后可更改容器防火墙，规则不是对进程自身的安全隔离。控制面允许直接出站，不能保护任意新增的未标记网络代码。简单 HTTP 代理不提供完整 HTTP/2、流水线/消息重构隔离，客户端应使用 HTTPS CONNECT 或 SOCKS5，不把本工具作为通用互联网代理服务。Web 是标准库实现；线程上限/容器资源限制不能替代压力和应用安全测试。节点不兼容或严格策略导致全部节点被拒绝时，保持失败关闭并人工分析，禁止自动降级验证、压缩或开放公网。

人工验收覆盖矩阵与具体命令见 [人工 Docker 验收](人工Docker验收.md)。没有静态证明足以替代这些运行结果。
